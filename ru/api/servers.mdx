title: "API серверов"
description: "HTTP-контракт Cevexa API для серверов, департаментов, участников, конвертации и интеграций."
---

Базовый URL: `https://api.cevexa.xyz`. Все эндпоинты требуют cookie сессии Cevexa (`cevexa_auth`), которую создаёт вход через Discord, и вызываются с `credentials: "include"`. Запросы, изменяющие данные, должны приходить с разрешённого origin (`cevexa.xyz` и его поддомены или настроенный origin).

## Ошибки

У всех ошибок одна форма:

```json
{ "error": "Понятное сообщение", "code": "server_has_departments" }
```

| Статус | Код | Когда |
|---|---|---|
| 400 | `invalid_request` | Некорректный JSON или неизвестные значения |
| 400 | `validation_failed` | Поле некорректно; `field` указывает какое |
| 400 | `provider_not_supported` | Провайдер интеграции недоступен |
| 401 | `unauthorized` | Нет действующей сессии |
| 401 | `discord_reauth_required` | Список гильдий Discord старше 24 часов или отсутствует; войдите через Discord ещё раз |
| 403 | `forbidden` | Вы участник, но ваша роль не разрешает действие |
| 403 | `origin_not_allowed` | Запрос пришёл с неразрешённого origin |
| 403 | `guild_not_manageable` | Вы не можете управлять этой гильдией Discord |
| 404 | `not_found` | Объект не существует **или вы не его участник** |
| 409 | `server_has_departments` | У сервера ещё есть департаменты |
| 409 | `invalid_parent` | Родитель не является обычным сервером |
| 409 | `not_a_department` / `not_a_server` | Действию нужен другой тип объекта |
| 409 | `already_this_type` | Конвертация в текущий тип |
| 409 | `integration_exists` | Внешний ресурс уже подключён к объекту Cevexa |
| 409 | `provider_already_connected` | У сервера уже есть интеграция этого провайдера |
| 409 | `connection_not_pending` | Подключение уже завершено, отменено, истекло или завершилось ошибкой |
| 503 | `service_unavailable` | Необходимое хранилище данных недоступно |

Для объектов, участником которых вы не являетесь, всегда возвращается `404`, чтобы не раскрывать их существование.

## Объекты

### Сервер

```json
{
  "id": "7c4f6a52-3a3e-4e5e-9a8e-0f1b2c3d4e5f",
  "type": "department",
  "name": "Fire Department",
  "description": null,
  "icon": null,
  "parent": { "id": "1b9d…", "name": "City RP", "icon": null },
  "role": "owner",
  "owner": { "id": "123456789012345678", "name": "alex", "avatar": "https://cdn.discordapp.com/…" },
  "memberCount": 1,
  "departmentCount": 0,
  "integrations": [
    { "id": "…", "provider": "discord", "status": "active", "externalResourceId": "123…", "externalResourceName": "City RP Fire", "connectedAt": "2026-11-17T12:00:00Z" }
  ],
  "createdAt": "2026-11-17T12:00:00Z",
  "updatedAt": "2026-11-17T12:00:00Z"
}
```

`role` — роль вызывающего пользователя. `owner` и `memberCount` возвращаются в ответах с одним объектом. ID пользователей — это ID пользователей Discord.

### Ожидающее подключение

```json
{
  "id": "…",
  "provider": "discord",
  "intent": "create_server",
  "status": "pending",
  "guildId": "123456789012345678",
  "guildName": "City RP",
  "serverId": null,
  "installUrl": "https://discord.com/oauth2/authorize?…",
  "expiresAt": "2026-11-17T12:15:00Z",
  "failureReason": null
}
```

## Серверы

| Метод | Путь | Роль | Описание |
|---|---|---|---|
| GET | `/v1/servers` | — | Серверы и департаменты, в которых вы состоите. Необязательно `?type=server\|department` |
| POST | `/v1/servers` | — | Создать сервер или департамент. Вы становитесь владельцем |
| GET | `/v1/servers/{serverId}` | member | Один сервер |
| PATCH | `/v1/servers/{serverId}` | administrator | Изменить `name`, `description`, `icon` (`null` очищает) |
| DELETE | `/v1/servers/{serverId}` | owner | Удалить. Возвращает `409 server_has_departments`, если не указан `?detachDepartments=true`, который сначала отвязывает департаменты |

Тело `POST /v1/servers`:

```json
{ "type": "department", "name": "Fire Department", "description": "Необязательно", "icon": "https://…", "parentServerId": "необязательно, обычный сервер, которым вы управляете" }
```

`name` — от 1 до 100 символов, `description` — до 1000, `icon` — URL `https` до 2048 символов.

## Департаменты

| Метод | Путь | Роль | Описание |
|---|---|---|---|
| GET | `/v1/servers/{serverId}/departments` | участник сервера | Департаменты, привязанные к обычному серверу. В каждом элементе — ваша `role` в департаменте или `null` |
| POST | `/v1/servers/{serverId}/departments` | administrator сервера | Создать департамент, привязанный к этому серверу. Вы становитесь его владельцем |
| PUT | `/v1/departments/{departmentId}/parent` | administrator департамента **и** нового родителя | Привязать или переназначить. Тело `{ "parentServerId": "…" }` |
| DELETE | `/v1/departments/{departmentId}/parent` | administrator департамента **или** его текущего родителя | Отвязать. Департамент остаётся рабочим |

## Конвертация

`POST /v1/servers/{serverId}/conversion` — только владелец.

```json
{ "targetType": "department", "parentServerId": "необязательно" }
```

```json
{ "targetType": "server" }
```

Возвращает обновлённый сервер с тем же `id`. См. [правила конвертации](/ru/platform/domain-model#конвертация).

## Участники

`GET /v1/servers/{serverId}/members` — любой участник.

```json
[{ "userId": "123456789012345678", "name": "alex", "avatar": null, "role": "owner", "joinedAt": "2026-11-17T12:00:00Z" }]
```

## Интеграции

| Метод | Путь | Роль | Описание |
|---|---|---|---|
| GET | `/v1/servers/{serverId}/integrations` | member | Интеграции сервера |
| POST | `/v1/servers/{serverId}/integrations` | administrator | Подключить гильдию Discord. Тело `{ "provider": "discord", "externalResourceId": "<id гильдии>" }`. `201 { "integration": … }`, если бот уже в гильдии, иначе `202 { "connection": … }` |
| DELETE | `/v1/servers/{serverId}/integrations/{integrationId}` | administrator | Отключить. `204` |

## Discord

| Метод | Путь | Описание |
|---|---|---|
| GET | `/v1/guilds` | Гильдии Discord из вашего последнего входа через Discord с полями `botInstalled`, `canManage` (владелец, Administrator или Manage Server) и `linked` (уже подключена к объекту Cevexa) |
| POST | `/v1/discord/connections` | «Начать с Discord»: создать новый сервер из гильдии. Тело `{ "guildId": "…", "name": "необязательно, по умолчанию название гильдии" }`. Ответ `{ "connection": …, "server": … }`; `server` есть только если подключение завершилось сразу (`201`), иначе `202` без `server` |
| GET | `/v1/discord/connections/{connectionId}` | Опрос подключения, которое вы начали. Завершает его, когда бот на месте. Всегда `200 { "connection": … }`; через 15 минут `status` становится `expired` |
| DELETE | `/v1/discord/connections/{connectionId}` | Отменить ожидающее подключение. `200 { "connection": … }` со `status: "cancelled"`; иначе `409 connection_not_pending` |

Список гильдий берётся из вашего последнего входа через Discord. Для начала подключения Discord список должен быть не старше 24 часов; иначе API вернёт `401 discord_reauth_required`, и нужно снова войти через Discord.
